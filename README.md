# ✈️ Voyage Analytics – Integrating MLOps in the Travel Industry

![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png)

## 🌍 Project Overview

The travel and tourism industry presents significant opportunities for innovation through data analytics and machine learning. By analyzing travel-related datasets, businesses can better understand customer preferences, identify travel patterns, and improve decision-making.

**Voyage Analytics** is a capstone project that integrates three key datasets — **Users, Flights, and Hotels** — to explore different aspects of travel behavior and preferences.

The project focuses on developing and deploying machine learning models that support predictive analysis and travel-related decision-making, while providing practical experience in implementing **Machine Learning Operations (MLOps)** practices.

![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png)

## 📖 Introduction

Voyage Analytics explores the application of data analytics and machine learning techniques in the travel and tourism industry.

Using the Users, Flights, and Hotels datasets, the project develops three machine learning solutions:

- ✈️ **Flight Price Prediction:** Predicts flight ticket prices using regression techniques.
- 👤 **Gender Classification:** Classifies user gender using a trained machine learning model.
- 🏨 **Hotel Recommendation System:** Helps users explore hotel options through a recommendation-based approach.

The project also focuses on deploying these solutions through a unified Streamlit application and applying practical MLOps concepts.

![-----------------------------------------------------](https://raw.githubusercontent.com/andreasbm/readme/master/assets/lines/rainbow.png)

## 🎯 Project Objectives

1. **Regression Model Development:** Develop a regression model using the flights dataset to predict flight ticket prices.

2. **Streamlit Application:** Build an interactive Streamlit web application that enables users to obtain flight price predictions.

3. **Containerization:** Package and deploy the machine learning model using Docker.

4. **Model Tracking:** Implement MLflow for tracking machine learning experiments and managing model versions.

5. **Gender Classification:** Develop and deploy a machine learning model for classifying user gender.

6. **Travel Recommendation System:** Build a hotel recommendation system and integrate it into the Streamlit application to provide interactive insights.

## 🚀 Getting Started

Follow the instructions below to set up the project locally.

### Prerequisites

Ensure that the following tools and technologies are installed on your system:

- Python 3.8+
- Git
- Docker
- MLflow
- Streamlit

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/maha2806/Voyage-Analytics.git
```

**2. Navigate to the project directory**

```bash
cd Voyage-Analytics
```

**3. Create a virtual environment**

```bash
python -m venv venv
```

**4. Activate the virtual environment**

Windows:

```bash
venv\Scripts\activate
```

Mac/Linux:

```bash
source venv/bin/activate
```

**5. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the Streamlit application**

```bash
python -m streamlit run app.py
```

The application will open in your browser, where you can explore the available machine learning modules.

## 💻 Application Modules

### ✈️ Flight Price Prediction

Predicts estimated flight ticket prices based on user-provided flight details, including:

- Departure city
- Arrival city
- Flight type
- Airline or agency
- Estimated flight duration
- Flight distance
- Number of passengers

### 👤 Name-Based Gender Classification

Uses a trained classification model and name embeddings to generate a predicted label and model confidence score.

*Note: This is a statistical prediction based on training data. A person's gender cannot be reliably determined from their name.*

### 🏨 Hotel Recommendation System

Allows users to explore hotel records using interactive filters such as:

- Destination
- Price per day
- Stay duration

Matching hotel results are displayed based on the selected criteria.
